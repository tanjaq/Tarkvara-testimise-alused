Homework 10 — Test Cases for Your Project

Group projectLesson 10Submit: Teams — SRS section 7.1

Objective

Close the loop: requirements you wrote in Lesson 4, verified by test cases you write now.

Task

  1. With your team, write test cases for your project and add them to your SRS document, section 7.1 Test Cases.
  2. The test cases must cover all of your functional requirements — check them off one by one.
  3. Each test case needs: ID and title, description, preconditions, numbered steps, test data, expected results, and a status column.
  4. Include negative and edge cases, not only the happy path. Use the techniques from Lessons 7 and 8 to decide which values to test.
  5. Keep each case focused on one scenario, and make sure no case depends on the output of another.

Deliverable

Test cases in the SRS document covering every functional requirement.

Assessment criteria

CriterionWhat we look for
TraceabilityEvery functional requirement has at least one test case, and every case names its requirement
ExecutableAnother team could run your cases without asking questions
Measurable expected resultsNo "works correctly"
Negative coverageInvalid input and edge cases are included

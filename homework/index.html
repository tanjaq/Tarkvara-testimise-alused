Homework

13 assignments · one per lesson · group work, pair work and individual exercises

Each assignment has a full brief with the task, what to hand in and how it is assessed. The group project runs through the whole course: requirements (Lesson 4) → architecture (Lesson 5) → test cases (Lesson 10) all land in the same SRS document.

Course materials used by the assignments

  • Testing process worksheet — Homework 3: Word version or fill in on the page
  • SRS document template — Homework 4 and 10
  • Trip planner form — Homework 7
  • shop-database.sql — Homework 11

All assignments

Homework 1 · Lesson 1
The Quality Mindset
Bring one high-quality and one poor-quality piece of software to discuss.
Homework 2 · Lesson 2
Failure Case Analysis
Analyse a real software failure and the testing that would have prevented it.
Homework 3 · Lesson 3
Test Process Worksheet — Calculator
Run all five ISTQB test process steps on a simple web calculator.
Homework 4 · Lesson 4
Requirements for Your Project
Write the SRS requirements for your own project: functional and non-functional.
Homework 5 · Lesson 5
Project Architecture
Draw the architecture of your project and justify the style you chose.
Homework 6 · Lesson 6
Peer Review — Rental Car
Review a real repository and report every defect and inconsistency you find.
Homework 7 · Lesson 7
Decision Table + EP/BVA
Build the discount decision table, and run EP and BVA against the trip planner form.
Homework 8 · Lesson 8
Boarding Pass — Coverage Analysis
Work out statement and branch coverage for two given tests, and add what is missing.
Homework 9 · Lesson 9
Exploratory Session + Bug Report
Run a charter-driven exploratory session, then file a real defect in the Bug-Reporting repo.
Homework 10 · Lesson 10
Test Cases for Your Project
Write the test cases for your own project and add them to the SRS.
Homework 11 · Lesson 11
SQL Verification — Shop Database
Verify requirements with SQL and find the data defects hiding in a sample database.
Homework 12 · Lesson 12
Accessibility Audit
Audit one public site and your own project against WCAG 2.2 level AA.
Homework 13 · Lesson 13
Mobile Test Charter
Build a device matrix, then break an app on a real phone with interruptions and bad network.
